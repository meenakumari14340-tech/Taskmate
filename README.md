# TaskMate – Student Task Manager

TaskMate is a responsive web application designed to help students organize their daily tasks, manage assignments, set priorities, and track their productivity efficiently. It provides a simple and user-friendly interface with task management tools to improve time management and daily planning.

### Key Features
- **Task Management:** Add, edit, and manage daily tasks.
- **Priority & Due Dates:** Assign High, Medium, or Low priority and set deadlines.
- **Progress Tracking:** Monitor completed and pending tasks with progress statistics.
- **Search & Sort:** Find and organize tasks easily.
- **Dark Mode:** Switch between light and dark themes.
- **Pomodoro Focus Timer:** Manage study sessions with a built-in focus timer.
- **Import & Export:** Back up and restore task data using files.
- **Auto Save:** Store task data in the browser.
- **Responsive Design:** Access the application across different screen sizes.
- **Multiple Pages:** Home, My Tasks, Calendar, Insights, About, and Contact.

### Technologies Used
HTML5, CSS3, JavaScript

### Project Type
Frontend Web Development

### Objective
To develop a simple and practical task management application that helps students stay organized, manage deadlines, and improve productivity.
