GOOD TO KNOW

Frequently asked questions

Does TaskMate need an account?

No. This prototype works directly in the browser, so there is no sign-up flow.

Where is my task data saved?

Tasks are saved in the browser's localStorage on this device. Use Export regularly to keep a JSON backup.

Can I use it on another computer?

Export your tasks from this browser, open TaskMate on the other computer and use Import to restore the backup.

Is this a cloud-synced application?

Not yet. This academic prototype uses local browser storage and does not sync data across devices.
